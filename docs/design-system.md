# Phase 2 — Visual Identity

## Design direction

Dakzo Systems uses a high-contrast editorial technology identity: dark ink, warm-white surfaces, restrained mint accent, large typography, generous spacing, and geometric system visuals.

## Logo system

- `site/assets/logo-mark.svg` — standalone mark / favicon / compact surfaces
- `site/assets/logo-dark.svg` — full logo for light backgrounds
- `site/assets/logo-light.svg` — full logo for dark backgrounds

The mark is a geometric D built from a strong outer form, internal system space, and a mint signal node representing connected technology.

## Core colors

| Token | Value | Role |
| --- | --- | --- |
| Ink | `#0B1020` | Primary text, dark surfaces |
| Ink Soft | `#263047` | Secondary dark text |
| Paper | `#F7F9FC` | Site background |
| White | `#FFFFFF` | Cards and light surfaces |
| Accent | `#63E6BE` | Signal / highlight |
| Accent Strong | `#31C89B` | Focus and stronger accent |
| Line | `#DCE2EC` | Borders |
| Muted | `#68748A` | Supporting text |

## Typography

System-first sans-serif stack to avoid blocking rendering and third-party font dependencies. Headings use tight tracking and compact line height; body copy prioritizes readability.

## Interface principles

- Rounded but not playful
- Strong spacing hierarchy
- Motion is subtle and optional
- Keyboard focus is always visible
- Mobile layouts are first-class
- Decorative graphics never carry essential information
