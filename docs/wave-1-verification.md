## Verification command

```bash
npm run verify
```

This runs:

1. HTML/content lint checks
2. Route and brand assertions
3. Accessibility-baseline assertions
4. Responsive/reduced-motion assertions
5. Production build generation

## Wave 1 acceptance baseline

- Seven public routes exist and resolve
- One H1 per page
- Page titles and descriptions are present
- Skip-link and main landmark exist
- All images include alt attributes
- Mobile navigation exposes ARIA expanded state
- Escape closes the mobile menu and returns focus
- Visible focus treatment exists
- Reduced-motion preference is respected
- Homepage identifies Dakzo Systems as a Dakik LLC company
- Homepage showcases HMD ERP, Congo Delivery, and Moto Track
- Homepage communicates custom software, ERP, application, logistics, tracking, website, and automation capabilities
